3Dプリンター用・誰でも簡単CAD

🔑 かんたん3D CAD

キーホルダーの3Dデータを、ブラウザだけで作れるアプリ。
アプリのインストールも、CADの知識もいりません。
🪪 名前プレート 好きな形の土台に名前をのせる。フォント・色・穴の場所も選べる。 2色プリント対応 作る ▶ 🔳 QRキーホルダー URLを入れるとQRコードのキーホルダーになる。スマホで読みとれるか その場で試せる。 読み取りチェック付き 作る ▶ 🔘 クリッカーメーカー 3Dモデル（STL / 3MF / GLB）を入れると、キースイッチでカチカチ押せる上下2パーツにしてくれる。 Cherry MX互換 作る ▶

使いかた

① 選ぶ作りたいものを上から選ぶ
② 作るステップに沿って進めるだけ。3Dですぐ見える
③ 保存STL または 3MF でダウンロード
④ 印刷スライサー（Bambu Studio など）に入れて3Dプリント
※ 作ったデータはこの端末の中だけで作られます。どこにも送信されません。
※ 開発中に手もとで動かすときは 起動.bat（＝ npm run dev）から開いてください。
