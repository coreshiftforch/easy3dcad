        ・概要       3Dプリンターで刷れるデータを、ブラウザだけで作れる。

        ・台本は「動画構成メモ.txt」

  □ 3. エントリーフォームに登録
        ・WebアプリなのでURLを記入

        ・サポートソフトウェア … 不要

        ・OSS・使用アセット … 「別添参照_使用OSS・アセット一覧.txt」

  □ 4. 事務局指定のストレージに提出資料をアップロード
        □ 作品データ一式（下記「提出するファイル」）

        □ 補足資料（この提出資料フォルダ）
        □ ウイルスチェックを実行してから送る


────────────────────────────────────────────────────────────────────
■ 提出するファイル（作品データ一式＝リポジトリの中身）
────────────────────────────────────────────────────────────────────

  含める                              理由
  ────────────────────────────────────────────────────────
  index.html / clicker.html           エントリのHTML
  src/                                クリッカーメーカーのソース（自作）
  public/                             3アプリ共通部分・単一HTML2本・
                                      フォント・vendor・ライセンス全文
  検算/                               自動検査（自作）
  package.json / package-lock.json    依存関係が分かるように
  vite.config.js                      ビルド設定
  .github/workflows/deploy.yml        自動検査＋自動公開の設定
  README.md                           構成と設計の説明
  起動.bat                            動かしかた
  提出資料/                           この4つのドキュメント

  含めない                            理由
  ────────────────────────────────────────────────────────
  node_modules/                       npm install で復元できる（数百MB）
  dist/                               ビルドで生成される
  .git/                               履歴（必要なら別途）

  ★動かしかたを一緒に書いておくと親切：
      npm install → npm run dev（http://localhost:5173/）
      あるいは 起動.bat をダブルクリック
      ※ビルド不要でも、dist/ を作れば静的ファイルとしてそのまま開ける
